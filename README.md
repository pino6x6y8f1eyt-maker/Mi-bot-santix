# 🎫 Sistema de Tickets - Los Panas Gamers

Bot de tickets con 4 categorías usando discord.js v14.

## Comandos
`/setup` → Crea el panel de tickets en el canal actual. Solo admins.

## Categorías
1. ❓ **Dudas** - Dudas sobre el servidor
2. 🚨 **Reportar usuario** - Reportes con pruebas 
3. 🤝 **Alianza** - Alianzas entre servidores
4. 👑 **VIP** - Soporte especial zona VIP

## Instalación
1. `npm install`
2. Crea `.env` con `TOKEN=tu_token`
3. `node index.js`
4. Usa `/setup` en tu servidor
